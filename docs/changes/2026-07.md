## 2026-07-02 - 할 일 핀 고정

### 요청 원문

> todo 할일 중 상단에 핀고정 할수있도록해줘. 핀 고정된건 항상 제일 위에 있도록.

### 결과 요약

- `todo_todos`에 `isPinned` 컬럼을 추가해 할 일별 핀 고정 상태를 저장하도록 했다.
- 할 일 카드에 `핀 고정` / `고정 해제` 버튼과 고정 배지를 추가했다.
- 검색/필터/정렬 상태와 관계없이 핀 고정된 할 일이 목록 최상단에 먼저 나오도록 정렬 로직을 변경했다.
- 서버 조회 기본 정렬도 `isPinned desc`, `createdAt desc` 순서로 맞췄다.
- Prisma 전체 `db push`는 공유 DB의 다른 테이블 삭제 경고가 있어 중단했고, 필요한 컬럼/인덱스만 `ALTER TABLE ... ADD COLUMN IF NOT EXISTS`와 `CREATE INDEX IF NOT EXISTS`로 안전하게 반영했다.

### 변경 파일

- `prisma/schema.prisma`
- `prisma/todo-init.sql`
- `src/app/(app)/todos/page.tsx`
- `src/app/actions/todo-actions.ts`
- `src/components/todo-dashboard.tsx`
- `docs/changes/2026-07.md`

### 검증

- `ALTER TABLE "todo_todos" ADD COLUMN IF NOT EXISTS "isPinned" boolean NOT NULL DEFAULT false` 적용 확인
- `CREATE INDEX IF NOT EXISTS "todo_todos_isPinned_idx" ON "todo_todos" ("isPinned")` 적용
- `npm.cmd run build` 성공
- `git diff --check` 통과
